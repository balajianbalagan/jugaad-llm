Jugaad LLM is a focused LangChain test bench for OpenAI-compatible local gateways — a clean place to check routes, models, prompts, and responses before they reach your product.

View the repository ↗ About the maker
01

Point it

Set an OpenAI-compatible base URL and model in a private local environment file.

02

Prompt it

Use the lightweight FastAPI interface to try prompts, system instructions, and temperature settings.

03

Ship with confidence

Keep the key server-side, validate the response path, then move the proven configuration into your app.

quick-start

git clone https://github.com/balajianbalagan/jugaad-llm.git
cd jugaad-llm
py -m venv .venv
pip install -r requirements.txt
uvicorn app:app --reload

Then open http://127.0.0.1:8000 and start testing.
